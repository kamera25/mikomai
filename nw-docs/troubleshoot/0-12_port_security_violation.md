## Problem: `ポートセキュリティ違反によるポートのErr-Disabled状態`

### Solve

1.  スイッチのインターフェース状態を確認し、`err-disabled` になっていないかチェックする[cite: 1]。
2.  ポートセキュリティの違反ログを確認し、許可されていないMACアドレスが接続されていないか特定する。
3.  原因となる端末を排除後、ポートを `shutdown` してから `no shutdown` して復旧させる。

### Explain

スイッチのポートにあらかじめ許可したMACアドレス以外の機器が接続されたり、許可数をオーバーしたりした場合に、ポートが自動的にシャットダウンされるセキュリティ機能によるものです。
