## Problem: `IPアドレスの競合による不安定な通信`

### Solve

1.  ARPテーブルを確認し、同一のIPアドレスに対して異なるMACアドレスが登録されていないか確認する[cite: 1]。
2.  該当のIPアドレスを使用している機器のログや、DHCPサーバーのリース状況を確認する。
3.  競合している端末の一方（または両方）のIPアドレスを変更する、あるいはDHCPの除外設定を見直す。

### Explain

固定IPアドレスの設定ミスや、DHCPプールと固定IPの重複により、ネットワーク上に同じIPアドレスを持つ機器が複数存在すると発生します。通信が頻繁に途切れたり、繋がったりする不安定な状態になります。
