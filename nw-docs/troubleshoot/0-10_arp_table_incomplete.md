## Problem: `ARP解決の失敗による同一セグメント内の通信不可`

### Solve

1.  端末やルーターでARPテーブル（`arp -a` や `show arp`）を確認し、対象IPのMACアドレスが解決されているか確認する[cite: 1]。
2.  対象機器のファイアウォール設定でARP応答がブロックされていないか確認する。
3.  L2スイッチのMACアドレスアドレステーブルを確認し、該当ポートに正しく学習されているか確認する。

### Explain

IPアドレスからMACアドレスを解決できないと、データリンク層での通信フレームを作成できず通信できません。機器の電源が落ちている、ケーブルが抜けている、またはセキュリティソフトによってARPがブロックされている場合などに発生します。
