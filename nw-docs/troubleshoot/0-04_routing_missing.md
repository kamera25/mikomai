## Problem: `ルーティング設定の欠如による別セグメントへの通信不可`

### Solve
 1. Pingで同一セグメント内への通信が可能か確認する。
 2. ルーターやL3スイッチのルーティングテーブル（`show ip route`等）を確認する[cite: 1]。
 3. 宛先ネットワークへのルート（静的ルートやデフォルトゲートウェイ）が正しく設定されているか確認し、不足していれば追加する。

### Explain
 異なるサブネット間での通信にはルーターやL3スイッチによるルーティングが必要です。特定のセグメント宛のルート情報が存在しない、またはデフォルトゲートウェイが設定されていないと、パケットは破棄されてしまいます。
