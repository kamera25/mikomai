## Problem: `ACL（アクセスコントロールリスト）による意図しない通信遮断`

### Solve
 1. ルーターやスイッチ、ファイアウォールのインターフェースに適用されているACLの設定を確認する[cite: 1]。
 2. ログ機能（`log`オプション）をACLに追加し、どのルールでドロップされているかを特定する。
 3. 必要な通信を許可するようにACLのルールを追加または修正する。

### Explain
 セキュリティ強化のために設定したACLが、必要な通信までブロックしてしまうケースです。ACLは上から順に評価され、最後に「暗黙のDeny」があるため、ルールの順序や記述ミスが原因となります。
