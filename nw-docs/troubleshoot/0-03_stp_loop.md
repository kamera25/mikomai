## Problem: `STPループによるネットワーク全体の遅延・通信断`

### Solve

1.  各スイッチのログを確認し、MACアドレスフラッピングの警告やSTPのトポロジ変更が頻発していないか確認する[cite: 1]。
2.  物理的な結線を確認し、意図しないループが形成されていないかチェックする。
3.  スパニングツリープロトコル（STP/RSTP）が各スイッチで有効になっているか、またルートブリッジが正しく設定されているか確認する。

### Explain

誤ったケーブル接続により物理ループが発生し、STPが無効化されている場合や設定に問題がある場合、ブロードキャストストームが発生してネットワーク全体がダウンします。早急に原因箇所（ループ部分）を物理的または論理的に切断する必要があります。
