## Problem: `VLANの不一致により通信ができない`

### Solve
 1. 対象スイッチのインターフェース設定を確認し、アクセスポートに割り当てられているVLAN IDを確認する[cite: 1]。
 2. 対向スイッチのインターフェース設定（トランクポートの許可VLANなど）を確認する[cite: 1]。
 3. 必要に応じて、正しいVLAN IDを再設定する。

### Explain
 オンプレミス環境で非常に多い設定ミスです。アクセスポートに誤ったVLANが割り当てられている場合や、スイッチ間を結ぶトランクリンクで必要なVLANが許可されていない場合に発生します。各ポートのVLAN設定を正確に合わせる必要があります。
