## Problem: `NAT/NAPTの設定ミスによる外部ネットワークへの通信不可`

### Solve
 1. ルーターやファイアウォールのNAT変換テーブル（`show ip nat translations` 等）を確認する[cite: 1]。
 2. 内部から外部への通信時に、プライベートIPが正しいパブリックIPに変換されているか確認する。
 3. NATルールの対象となる内部ネットワーク（ACLなど）が正しく指定されているか見直す。

### Explain
 プライベートネットワークからインターネットなどの外部ネットワークへ通信する際、IPアドレスの変換（NAT）が必須です。変換ルールが間違っていると、外部へのパケットが出て行かない、または戻りのパケットが内部へルーティングされません。
