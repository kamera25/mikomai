## Problem: `ネットワーク機器のリソース（CPU/メモリ）枯渇による通信遅延やドロップ`

### Solve
 1. ルーターやスイッチのリソース使用状況（`show processes cpu` や `show memory`）を確認する[cite: 1]。
 2. 特定のプロセス（ルーティングプロトコル、SNMP、ACL処理など）がCPUを占有していないか特定する。
 3. 不要なサービスの停止、ファームウェアのバグ確認、またはより上位の機器へのリプレースを検討する。

### Explain
 機器の処理能力を超えるトラフィック（DDoS攻撃やルーティングループなど）が発生した場合や、ソフトウェアのバグによりリソースが枯渇すると、正常なパケットの処理が追いつかず、ネットワーク全体が遅延・不安定になります。
