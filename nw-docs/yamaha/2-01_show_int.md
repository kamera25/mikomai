## Command: `show status lan1`

### Description

このコマンドを入力すると、LAN1インターフェースのステータスを表示できます。
このコマンドはYamahaでしか使えません。

### Usage

```text
#show status lan1
```

### Output

```text
LAN1
IP Address: 192.168.100.1/24
Ethernet Address: 00:a0:de:11:22:33
Link status: UP
```
