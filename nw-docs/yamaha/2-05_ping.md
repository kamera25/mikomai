## Command: `ping`

### Description

このコマンドを入力すると、ICMPエコー要求を送信して宛先との疎通確認ができます。
このコマンドはYamahaでしか使えません。

### Usage

```text
#ping 192.168.100.2
```

### Output

```text
192.168.100.2 is alive
```
