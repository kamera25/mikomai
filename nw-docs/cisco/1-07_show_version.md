## Command: `show version`

### Description

このコマンドを入力すると、IOSのバージョン情報や稼働時間、ハードウェアの情報などを表示できます。
このコマンドはCiscoでのみ使えます。

### Usage

```text
#show version
```

### Output

```text
Cisco IOS XE Software, Version 16.9.1
Cisco IOS Software [Fuji], Catalyst L3 Switch Software (CAT9K_IOSXE), Version 16.9.1, RELEASE SOFTWARE (fc2)
```
