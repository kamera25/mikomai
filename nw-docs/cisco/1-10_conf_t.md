## Command: `configure terminal`

### Description

このコマンドを入力すると、特権EXECモードからグローバルコンフィギュレーションモードに移行し、機器全体の設定が可能になります。
このコマンドはCiscoでのみ使えます。

### Usage

```text
#configure terminal
```

### Output

```text
Enter configuration commands, one per line.  End with CNTL/Z.
Router(config)#
```
