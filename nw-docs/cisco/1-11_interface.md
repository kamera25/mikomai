## Command: `interface GigabitEthernet1/0/1`

### Description
 このコマンドを入力すると、指定したインターフェースのコンフィギュレーションモードに移行します。
 このコマンドはCiscoでしか使えません。

### Usage

```text
#interface GigabitEthernet1/0/1
```

### Output

```text
Router(config-if)#
```
