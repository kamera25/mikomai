## Command: `no shutdown`

### Description

このコマンドを入力すると、インターフェースを有効化（起動）できます。
このコマンドはCiscoでのみ使えます。

### Usage

```text
#no shutdown
```

### Output

```text
%LINK-3-UPDOWN: Interface GigabitEthernet1/0/1, changed state to up
%LINEPROTO-5-UPDOWN: Line protocol on Interface GigabitEthernet1/0/1, changed state to up
```
