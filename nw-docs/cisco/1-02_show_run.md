## Command: `show running-config`

### Description

このコマンドを入力すると、現在稼働中の設定ファイル（running-config）を表示できます。
このコマンドはCiscoでのみ使えます。

### Usage

```text
#show running-config
```

### Output

```text
Building configuration...
Current configuration : 1000 bytes
!
version 16.9
!
hostname Router
```
