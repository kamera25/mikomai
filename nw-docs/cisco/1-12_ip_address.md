## Command: `ip address 192.168.1.1 255.255.255.0`

### Description
 このコマンドを入力すると、インターフェースにIPアドレスとサブネットマスクを設定できます。
 このコマンドはCiscoでしか使えません。

### Usage

```text
#ip address 192.168.1.1 255.255.255.0
```

### Output

```text
Router(config-if)#
```
